# Guía de Contribución

## Flujo de trabajo
- Crear una rama con tu nombre (ivan, carlos, etc.)
- No trabajar directamente en main
- Hacer commits claros y descriptivos

## Pull Requests
- Explicar qué se hizo
- Esperar revisión del equipo
- No hacer merge sin aprobación

## Estándares de código
- Usar camelCase para funciones y variables
- Mantener código limpio y organizado
- Comentar funciones importantes
